## Design idea

The visual theme comes from sewing and design: a dashed "thread" on the left edge that stitches itself as you scroll, stitched-edge cards, tilted stickers, and stitched underlines under each heading.

## Features

- Fully responsive (desktop and mobile)
- Light and dark mode (follows system setting, with a manual toggle)
- Scroll-driven thread animation and animated headings
- Respects reduced-motion settings
- Keyboard-friendly navigation and visible focus states
- Resume download button
- No frameworks or build step: one HTML file with inline CSS and JavaScript

## Tech

HTML, CSS, vanilla JavaScript. Fonts: Bricolage Grotesque and DM Sans (Google Fonts).

## Run locally

Open `index.html` in any browser. No install needed.

## Deploy on GitHub Pages

1. Create a new public repository on GitHub.
2. Upload all files from this folder (keep `index.html` in the root).
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. After a minute, your site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`.

Other options: drag the folder into Netlify Drop, or import the repo into Vercel.
